# План первого внедрения — Gordey_ap01

Поручение: начать Personal Corp 3 на доступных проектах и максимально самостоятельно подготовить дальнейшую работу.

1. Использовать существующий куратор портфеля как источник фактов; отдельно проверить доступность папок, не изменяя приложения.
2. Собрать локальный штаб: профиль подтверждённых предпочтений, связи с действующими инструментами, очередь с доказательствами и ежедневный обзор.
3. Подготовить один полезный результат для выбранного владельцем направления «сначала собственный бренд, затем клиенты».
4. Проверить сохранение состояния, ограничения очереди, приватность Git и интерфейс в браузере.
5. Передать владельцу результат и одно действие для проверки реальной пользы. Пользу считать неизвестной до фактического применения.

Сначала личное использование и проверяемые результаты. Постоянный фоновый исполнитель и публикация не входят в первый запуск.
