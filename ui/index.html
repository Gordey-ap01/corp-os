01

Первая неделя · один цикл

Открыть штаб → взять один результат → применить → записать замечания. До применения экономия времени неизвестна.

02

Вторая неделя · повторить

Повторить полезный сценарий три раза. Записать фактическое время, переделки и результат. Сравнить с ручным процессом, если есть исходный замер.

03

Третья и четвёртая · расширить

Подключить ещё один процесс из работы или обучения. Личную жизнь добавлять по конкретной задаче, без догадок о здоровье, финансах и привычках.
